## 💡 What is Rasd?

**Rasd** (رَاصِد — *"observer"*) is a desktop app for engineers and engineering offices who live inside folders full of drawings, PDFs, spreadsheets, and calculation sheets.

Instead of digging through nested directories, Rasd **indexes each project's folder**, lets you **search it instantly**, **preview files without opening them**, and keeps your **tasks and calendar** tied to the project they belong to.

Everything stays **on your machine**. No account, no cloud, no subscription.

## ✨ Features

### 📁 Project Explorer & Indexer
- **Index a whole project folder** and browse it with a fast, familiar file view.
- **Live file-type counters** — jump straight to Excel, PDF, Word, Images, CAD, and more with one click.
- **Hashtag filters** and **specializations** (e.g. `#irrigation`) to group folders by discipline.
- **Quick access** — Favorites, Recently opened, Recently added, and a Change log per project.
- **Trash bin** per project — restore deleted items or remove them permanently.

### 🔎 Instant Search
- Search by **name, path, extension, or hashtag**, scoped to a single project.
- **Save your searches** and re-run them later.
- Results update while you type.

### 👁️ Built-in Preview
- Preview **images, PDFs, and DWG drawings** in the side panel without leaving Rasd.
- See file size, type, folder, modified date, last opened, and tags at a glance.
- Single-click to preview, double-click to open.

### ✅ Smart Tasks & Calendar
- **Project-linked tasks** with priority, date, time range, and hashtags.
- **Step checklists** inside each task with live progress (e.g. `0/3`).
- **Two-way TXT sync** — every task is also a plain `.txt` file inside the project, so you can edit it from either side.
- **Calendar views:** Month · Week · Day · Agenda.
- **Drag & drop** tasks to reschedule, drag the bottom edge to change duration, click an empty slot to create a task (15-minute steps).
- **Print / export to PDF** from the task list.

### 🔐 Privacy & Maintenance
- **Optional startup password** to lock the app.
- **Export / Import projects** to back up or share your workspace.
- **Custom storage path** — keep your data wherever you want, or restore the default.
- **Update checker** that reads GitHub Releases.

## 🚀 Getting Started

### Install (recommended)

1. Go to the [**Releases**](https://github.com/engamrhesham2002-cell/Rasd/releases/latest) page.
2. Download the latest installer / `.exe`.
3. Run it and click **Start**.
4. Press **New Project**, pick your project folder, and let Rasd index it.

> **Requirements:** Windows 10 or 11.

### Quick tour

| Want to… | Do this |
|---|---|
| Add a project | **+ New Project** on the home screen |
| Find a file | Use the search bar, or open the project search page |
| Preview a file | Click it once |
| Open a file | Double-click it |
| Add a task | **Tasks** (bottom bar) → **Add task** |
| Reschedule a task | Drag it in the calendar |
| Back up everything | **Import/Export** at the top of the home screen |
